YOURS SALON

Data Port

Import or export Employee, Customer Entry, and Expense Type data as CSV or Excel (.xlsx).

Exports include all records. Employee imports update matching Employee IDs; Expense Type imports update matching SR values. Customer Entry imports update a matching MongoDB _id, while rows without an _id are added as new entries. Keep exported _id values unchanged when restoring Customer Entry data.

Employee

Includes custom employee fields. Import requires Employee ID and Employee Name; existing Employee IDs are updated.

Customer Entry

Includes entry date, payment and amount details. Customer Entry import validates the full file before saving any row.

Expense Type

Includes serial number, name, and status. Imports update matching SR values.
